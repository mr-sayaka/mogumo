# mogumo

## サイト概要
### サイトテーマ
 - 離乳食に関する悩みや情報をユーザー同士で共有し、子育て中の親が安心して離乳食を勧められる場を提供するコミュニティサイト

### テーマを選んだ理由
- 自分自身に離乳食を食べる子どもがおり、離乳食を進める中で「何を食べさせたらいいか」「この食材はいつから食べられるのか」など、分からないことや迷うことが多くありました。
そこで、同じように離乳食について悩んでいる子育て中の方が、気軽に情報を共有したり、他の人の経験を参考にしたりできる場があれば便利だと思い、このテーマを選びました。

​
### ターゲットユーザ
- 初めての子育てで、離乳食について分からないことが多い人
- 「何を食べさせたらいいか」「いつから食べられるか」など悩んでいる人
- 他の家庭の離乳食やレシピを参考にしたい人

### 主な利用シーン
- 離乳食の進め方た食材について分からないことがあるとき
- 他の家庭の離乳食メニューやレシピを参考にしたいとき
- 自分が作った離乳食を共有したいとき​
